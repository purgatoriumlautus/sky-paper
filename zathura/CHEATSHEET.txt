ZATHURA KEYBIND CHEATSHEET  —  stock defaults (no rebinds in zathurarc)
Press F1 inside zathura for the built-in help.
=====================================================================

NAVIGATE WITHIN PAGE
  j / k            scroll down / up
  h / l            scroll left / right
  d / u            half page down / up
  <C-d> / <C-u>    half page down / up
  <Space>          page down
  <S-Space>        page up

PAGES
  J / K            next page  /  previous page
  <C-PgDn>/<PgUp>  same
  gg               first page
  G                last page
  <N>G             jump to page <N>          (e.g. 42G)
  o                "open page <n>" prompt
  <Tab>            toggle index (table of contents)

ZOOM / FIT
  +  /  -          zoom in / out
  =                zoom to default
  a                fit width
  s                fit page (best fit)
  <N>z             set zoom to N%            (e.g. 150z)
  <C-r>            rotate 90°

VIEW
  r                recolor mode (toggle; uses palette via zathurarc)
  d                dual-page toggle
  i                invert colors

SEARCH
  /pattern         search forward
  ?pattern         search backward
  n / N            next / previous match
  Esc              clear

MARKS / JUMPS
  m<a..z>          set mark
  '<a..z>          jump to mark
  <C-o> / <C-i>    jump history back / forward

ANNOTATIONS / LINKS
  f                follow link on page (hint-style)
  F                copy link target
  <C-c>            copy selection (mouse-drag to select first)

FILES
  :open <path>     open file
  :write <path>    save copy
  R                reload current file
  <C-c>            cancel current prompt
  q                quit

DEPLOY
  stow zathura                      # symlinks ~/.config/zathura → here
  ./zathura/install.sh              # pacman pkgs + xdg-mime defaults (sudo)
