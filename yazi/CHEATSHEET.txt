YAZI KEYBIND CHEATSHEET  —  stock defaults, plus the one override below
Press ~ or <F1> inside yazi for the live, searchable help.
=====================================================================

NAVIGATE
  j / k            down / up               (arrows work too)
  h / l            parent dir / enter dir
  H / L            history back / forward
  gg / G           top / bottom
  <C-u> / <C-d>    half page up / down
  <C-b> / <C-f>    full page up / down
  gh               go ~                    gc   go ~/.config
  gd               go ~/Downloads          g<Space>  jump (interactive)
  gf               follow hovered symlink
  z / Z            jump via fzf / zoxide

SELECT
  <Space>          toggle selection, move down
  v / V            visual select / visual unset
  <C-a>            select all
  <C-r>            invert selection
  <Esc>            OVERRIDDEN in keymap.toml → go to parent dir (mirrors `h`).
                   Stock <Esc> — clear selection / clear find / clear filter —
                   is gone; use `,` or <Bspace> to clear a find or filter.

FILE OPS
  o / <Enter>      open                    O   open interactively (pick app)
  y / x            yank copy / yank cut
  p / P            paste / paste (overwrite)
  -  / _           symlink abs / relative   <C-->  hardlink
  Y / X            cancel yank
  d                TRASH (recoverable: gio trash --list)
  D                DELETE permanently (confirm)
  a                create file  (end name with / for a directory)
  A                bulk create
  r                rename

PREVIEW (right pane, always on)
  K / J            scroll preview up / down 5
  <Tab>            spot hovered file (detailed info popup)

VIEW / SORT
  .                toggle hidden files
  ms mp mb mm mo mn   linemode: size / perms / btime / mtime / owner / none
  ,a ,A            sort alpha / reverse        (,n natural)
  ,s ,S            sort size / reverse
  ,m ,M            sort mtime / reverse        (,b btime, ,e extension)
  ,r               sort random

FIND / FILTER / SEARCH
  / ?              find next / prev (in current dir)
  n / N            repeat find next / prev
  f                filter (live narrow current dir)
  s / S            search by name (fd) / by content (rg)
  <C-s>            cancel search

COPY PATH (to clipboard)
  cc               full path           cd   directory path
  cf               filename            cn   filename without extension

SHELL
  ;                run shell command
  :                run shell command, block until it finishes

TABS
  tt               new tab in CWD       tr   rename tab
  1..9             switch to tab N
  [ / ]            prev / next tab      { / }  move tab left / right

TASKS / MISC
  w                task manager (then j/k, <Enter> inspect, w/<Esc> close)
  ~ / <F1>         help
  q                quit           Q  quit without cwd-file
  <C-c>            close tab (quit if last)     <C-z>  suspend

NOTES
  - Trash uses the XDG trash spec (no extra binary). Restore with a trash
    tool or your file manager.
  - Image preview = kitty graphics (auto). Video/PDF thumbnails need
    ffmpegthumbnailer + poppler — run ./install.sh.
