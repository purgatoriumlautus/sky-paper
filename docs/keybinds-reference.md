# Справочник биндов

Все бинды всех слоёв, таблицами. Почему они такие — `keybinds.md`;
здесь только «что нажать и что будет».

Порядок перехвата на Linux: `keyd → niri → kitty → tmux → (nvim | fish)`.
Кто поймал первым, тот и съел. Приложения, живущие в терминале (yazi, nvim),
получают клавишу последними; niri и keyd — первыми.

Источник каждой таблицы — сам конфиг, а не память: если таблица разошлась с
конфигом, права таблица неправа.

---

## 1. keyd — `keyd/etc/keyd/default.conf`

Работает ниже композитора, по физическим keycode'ам, поэтому раскладка на
него не влияет вообще.

| Нажатие | Что уходит дальше |
|---|---|
| `CapsLock` | `Ctrl` |
| `Shift+CapsLock` | настоящий `CapsLock` |
| левый нижний `Ctrl` | `Menu` → переключение раскладки (xkb `grp:menu_toggle`) |
| `Super+C` | `Ctrl+Insert` — копировать |
| `Super+V` | `Shift+Insert` — вставить |
| `Super+X` | `Shift+Delete` — вырезать |
| `Super+A` | `Ctrl+A` — выделить всё |
| `Super+Z` | `Ctrl+Z` — отменить (в терминале это SIGTSTP, лечится `fg`) |
| `Super+Shift+Z` | `Ctrl+Shift+Z` — вернуть |
| `Super+←` / `→` | `Home` / `End` |
| `Super+↑` / `↓` | `Ctrl+Home` / `Ctrl+End` |
| `Alt+←` / `→` | `Ctrl+←` / `→` — по словам |
| `Alt+Shift+←` / `→` | `Ctrl+Shift+←` / `→` — выделить слово |

`Super+S` намеренно не переводится: `Ctrl+S` в терминале это XOFF.

## 3. kitty — `kitty/.config/kitty/kitty.conf`

`kitty_mod` = `Ctrl+Shift`.

| Бинд | Действие |
|---|---|
| `Ctrl+Insert` | `copy_or_noop` — копировать своё выделение, иначе пропустить клавишу дальше |
| `Shift+Insert` | вставить из буфера |
| `kitty_mod+C` / `kitty_mod+V` | копировать / вставить (работают по ssh) |
| `kitty_mod+S` | вставить из primary selection |
| `kitty_mod+O` | отдать выделение программе |
| `kitty_mod+↑` / `↓`, `kitty_mod+K` / `J` | скролл на строку |
| `kitty_mod+PgUp` / `PgDn` | скролл на страницу |
| `kitty_mod+Home` / `End` | в начало / конец скроллбэка |
| `kitty_mod+H` | открыть скроллбэк в пейджере |

Кириллические дубли: `kitty_mod+с м ы щ л о р`.

**Проглатываемые дыры** (`discard_event`) — `Super+S`, `Super+T`, `Super+N`,
`Super+P`, `Super+/`, `Super+Shift+Q`. Это клавиши, которые niri себе не
берёт, а tmux сворачивает `Super` в `Meta` и исполняет как свои `M-`;
`Super+T` вдобавок доходил до nvim и открывал терминал.

## 4. tmux — `tmux/.config/tmux/tmux.conf`

Root-таблица очищена (`unbind-key -a -T root`), поэтому всё, что здесь не
перечислено, проходит насквозь в панель. Префикс — дефолтный `Ctrl+B`.

Бинды с пометкой **→nvim** обёрнуты в `if-shell`: если в панели запущен nvim,
нажатие уходит ему, иначе его исполняет tmux.

| Бинд | Действие |
|---|---|
| `Alt+H` / `J` / `K` / `L` | **→nvim** фокус панели влево / вниз / вверх / вправо |
| `Alt+Shift+H/J/K/L` | **→nvim** ресайз панели |
| `Alt+V` / `Alt+S` | **→nvim** сплит вертикальный / горизонтальный |
| `Alt+Q` | **→nvim** закрыть панель |
| `Alt+Enter` | новое окно |
| `Alt+1..9` | окно N |
| `Alt+N` / `Alt+P` | следующее / предыдущее окно |
| `Alt+Space` | `sesh` — прыжок в проект |
| `Alt+Z` | copy-mode (повторное нажатие — выход) |
| `Alt+/` / `Alt+?` | copy-mode + поиск вниз / вверх |
| `Alt+R` | перечитать конфиг |
| `Alt+D` | detach |
| `Alt+Shift+Q` | убить сессию (с подтверждением) |
| `PageUp` | copy-mode со скроллом |
| `PageDown` | уходит в приложение как есть |
| колесо вверх / вниз | copy-mode / скролл в приложении |
| `префикс z` / `префикс d` | copy-mode / detach |

### copy-mode (vi)

| Бинд | Действие |
|---|---|
| `v` | начать выделение |
| `y` | скопировать в системный буфер и выйти |
| `Ctrl+Insert` | то же — приходит от `Super+C` |
| `q` | выйти |
| `h j k l w b e W B E g G H M L n N` | движение как в vim |

Кириллица: 17 дублей в root-таблице, 22 в copy-mode.

Изменённое репозиторием — **★**, остальное стоковое.

| Бинд | Действие |
|---|---|
| `h` / `l` | ★ перемотка ∓5 с |
| `H` / `L` | ★ перемотка ∓60 с |
| `j` / `k` | ★ громкость ∓2 |
| `J` / `K` | ★ следующая дорожка субтитров / звука |
| `g` / `G` | ★ в начало / в конец |
| `/` | ★ выключено (стоково убавляло громкость) |
| `Пробел` / `p` | пауза |
| `f` | полный экран |
| `m` | mute |
| `s` | скриншот |
| `[` / `]` | скорость воспроизведения |

| `↑` / `↓` | перемотка ±60 с |
| `9` / `0` | громкость |

Кириллица: 15 дублей.

## 10. Obsidian — `obsidian/vimrc` + `obsidian/hotkeys.json`

Три слоя: vim-режим (работает только в редакторе), Alt-ярус и Ctrl-аккорды
приложения (работают везде, включая граф, канвас и настройки).

### Ярус Пробел (vimrc, только редактор)

Требует `unmap <Space>` — без него `<Space>` занят движением и не может
начинать аккорд.

| Бинд | Действие |
|---|---|
| `Пробел Пробел` | найти файл |
| `Пробел /` | поиск по хранилищу |
| `Пробел :` | палитра команд |
| `Пробел Enter` | новая заметка |
| `Пробел w` | сохранить |
| `Пробел q` | закрыть вкладку |
| `Пробел n` | левый сайдбар |
| `Пробел e` | показать активный файл в дереве |
| `Пробел t` | вставить шаблон |
| `Пробел d` | граф (дашборда в Obsidian нет) |
| `Пробел 1..8` | вкладка N |
| `Пробел 9` / `Пробел 0` | последняя вкладка |

### Vim (vimrc)

| Бинд | Действие |
|---|---|
| `H` / `L` | предыдущая / следующая вкладка |
| `Ctrl+O` / `Ctrl+I` | назад / вперёд по истории |
| `Esc` | снять подсветку поиска |
| `p` (visual) | вставить поверх, не затирая регистр |
| `+` / `-` | инкремент / декремент числа |
| `Ctrl+A` | выделить всю заметку |
| стрелки | отключены |

### Ярус Alt (hotkeys.json, работает везде)

| Бинд | Действие |
|---|---|
| `Alt+1..8` | вкладка N |
| `Alt+9` | последняя вкладка |
| `Alt+N` / `Alt+P` | следующая / предыдущая вкладка |
| `Alt+Enter` | новый файл |
| `Alt+Q` | закрыть вкладку |
| `Alt+B` | добавить в закладки |
| `Alt+T` | вставить шаблон |
| `Alt+[` / `Alt+]` | назад / вперёд по истории |

Кириллические дубли: `Alt+Й И Т З Е`.

## 11. Firefox — Vimium, `firefox/vimium-keymap.txt`

Конфиг живёт в storage расширения; файл в репозитории авторитетен, живой
браузер — нет. Не работает на `about:*`, `view-source:*`,
`addons.mozilla.org` и странице новой вкладки.

| Бинд | Действие |
|---|---|
| `Alt+1..9` | вкладка N (нативно в Firefox) |
| `H` / `L`, `Alt+H` / `Alt+L`, `Alt+P` / `Alt+N` | предыдущая / следующая вкладка |
| `Alt+Q` | закрыть вкладку |
| `Alt+Enter` | новая вкладка |
| `Ctrl+O` / `Ctrl+I`, `Alt+J` / `Alt+K` | назад / вперёд по истории |
| `Alt+Z` | режим выделения (как copy-mode в tmux) |
| `f` / `F` | хинты: перейти / в новой вкладке |
| `s` / `S` | то же (мышечная память flash) |
| `Пробел` / `Пробел Пробел` | адресная строка: история, закладки, вкладки |
| `Пробел ,` | список вкладок |
| `Пробел e` / `Пробел b` | закладки |
| `Пробел q` | закрыть вкладку |
| `j` / `k`, `Ctrl+D` / `Ctrl+U` | скролл |
| `gg` / `G` | верх / низ страницы |
| `/` `n` `N` | поиск по странице |
| `yy` / `yf` | копировать адрес страницы / ссылки |
| `X` `i` `?` | вернуть вкладку, insert-режим, помощь |

Сняты голые `t`, `T`, `x` (создание, поиск и закрытие вкладки одной
буквой — слишком лёгкий промах) и `J`/`K` (у Vimium это вкладки, а в
схеме они на `H`/`L`).

Кириллица: 45 дублей. Хинты дублями не чинятся — в Options нужна галочка
filtered hints, тогда метки становятся цифрами.
