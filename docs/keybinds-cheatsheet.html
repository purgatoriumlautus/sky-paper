Пробел
Действия внутри редактора. Без модификаторов.
Alt
Границы контейнеров. Одинаково на обеих машинах.
Ctrl
Правка строки в шелле. CapsLock.
Super
Окна на десктопе. Только Linux.

Правило. Пока ты в normal mode — буквы свободны, модификатор не нужен. Как только ты в терминале — буквы это текст, и бинд без модификатора просто напечатается.

Физика. CapsLock = Ctrl на обеих машинах · leader = SPC (пробел) · под большим пальцем на обеих машинах: Super Alt SPC (на маке — свап Cmd/Option)

Три сущности vim

буферфайл в памяти. Их 50.
окнорамка на экране. = editor group в VSCode
вкладканабор окон, раскладка. Не файл.

20 файлов = 20 буферов и одна вкладка. Два файла рядом: Alt+v → SPCSPC → Alt+h/l.

Порядок внедрения

1CapsLock=Ctrl и swap Super/Alt на обеих машинах. Пожить пару дней.
2Ярус Alt в tmux и nvim. Не биндить Alt+t в tmux — иначе nvim его не увидит.
3Дерево SPC в nvim. mapleader = ' '
4Мак: VSCodeVim, keybindings.json.

Раскладка уехала с Alt+⇧ на Ctrl+SPC (бинд niri switch-layout, не xkb-опция) — иначе ресайз будет её переключать.

Настройки VSCode

  • macOptionIsMeta — true. Без неё ⌥ это клавиша композиции, весь ярус Alt мёртв.
  • allowChords — false. Иначе VSCode съедает Ctrl+k.
  • commandsToSkipShell — префикс - отдаёт нажатие шеллу.
  • enablePersistentSessions — true. Терминал переживает обрыв SSH.
  • Списки ходят по vim через listFocus && !inputFocus → list.focusDown/Up, list.collapse/expand.

Почему Super свободен

Super физически не доходит до терминального приложения, поэтому этот ярус не может столкнуться ни с Alt, ни с Ctrl, ни с SPC — его можно нагружать свободно.

Исключение — ◆+c/v: niri их намеренно не занимает, они проваливаются в kitty. Поэтому центрирование колонки уехало на ◆+⇧+c, а floating — с v на g.

Клавиши громкости, микрофона, яркости и плеера работают напрямую, в том числе на заблокированном экране.
