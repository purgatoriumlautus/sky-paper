OBSIDIAN KEYBIND CHEATSHEET  —  celestia
=========================================================================

Two layers:
  - vimrc                → CodeMirror 6 vim, pure-vim only
  - hotkeys.json         → Obsidian's app-level Ctrl-chord hotkeys
                           (works in vim & non-vim modes equally)

CodeMirror 6 vim CANNOT do (so these moved to hotkeys.json):
  - :let mapleader              ignored
  - :set langmap                ignored
  - noremap / nnoremap family   only nmap/vmap/imap exist
  - <Space>-prefix leader binds fire unreliably

-------------------------------------------------------------------------
PURE VIM   (~/.obsidian.vimrc, via 'Vimrc Support' community plugin)
-------------------------------------------------------------------------
  <Esc>            clear search highlight
  p (visual)       paste over selection, don't clobber register
  +  /  -          increment / decrement number under cursor
                   (<C-a>/<C-x> remapped onto these so <C-a> can do select-all)
  <C-a>            select whole note (gg V G)
  arrow keys       disabled (use hjkl)

-------------------------------------------------------------------------
OBSIDIAN HOTKEYS — defaults already in place (no override needed)
-------------------------------------------------------------------------
  Ctrl+O           quick switcher           (fuzzy file picker)
  Ctrl+Shift+F     global search            (across vault)
  Ctrl+P           command palette
  Ctrl+F           find in current note
  Ctrl+E           toggle edit / preview
  Ctrl+B           toggle bold              (around selection or word)
  Ctrl+I           toggle italic
  Ctrl+K           insert link
  Ctrl+1..6        set heading H1..H6
  Ctrl+0           remove heading (back to paragraph)
  Ctrl+Enter       follow link under cursor
  Ctrl+,           open settings
  Ctrl+S           save

-------------------------------------------------------------------------
OBSIDIAN HOTKEYS — added by this pkg (hotkeys.json)
-------------------------------------------------------------------------
  Ctrl+`           toggle inline code
  Ctrl+Alt+]       heading cycle UP    (paragraph → H6 → H5 → … → H1)
  Ctrl+Alt+[       heading cycle DOWN  (H1 → H2 → … → H6 → paragraph)
                   does NOT wrap.
  Ctrl+\           toggle left sidebar (file tree)

-------------------------------------------------------------------------
NOT MIRRORED  — no Obsidian analog, runs unbound:
-------------------------------------------------------------------------
  <leader>rn / ca          LSP rename / code action
  ]c / [c / <leader>h[prb] gitsigns hunks
  <leader>g*               DiffView
  <leader>t / q            terminal toggle

-------------------------------------------------------------------------
THEME (Flexoki)
-------------------------------------------------------------------------
  flexoki/{theme.css,manifest.json}
                           → ~/Documents/Obsidian/.../.obsidian/themes/Flexoki/
  Official theme, vendored from github.com/kepano/flexoki-obsidian
  (Flexoki's author Steph Ango is Obsidian's CEO). Replaces the old
  custom Sky Paper snippet. It only remaps the default theme's color
  variables — light and dark both painted; we run dark
  (appearance.json theme="obsidian", the DARK base).
  Accent overridden to #8B7EC8 (Flexoki purple-400, see PALETTE.md).
  If the theme isn't active after install, select it once:
  Settings → Appearance → Themes → Flexoki.

FONT
  Already set in app.json — Terminess Nerd Font for interface/text/mono.
  obsidian-fonts.conf in fontconfig/ forces AA+hinting on at all sizes
  so Obsidian doesn't render bitmap-broken at base 16px.

-------------------------------------------------------------------------
DEPLOY
-------------------------------------------------------------------------
  ./obsidian/install.sh
    - pacman: obsidian jq
    - links flexoki/theme.css + manifest.json → vault themes/Flexoki/
    - removes the old sky-paper.css snippet link if present
    - links vimrc → vault root .obsidian.vimrc
    - links hotkeys.json → vault .obsidian/hotkeys.json
    - patches appearance.json (theme=obsidian dark, cssTheme=Flexoki,
      accent #8B7EC8, sky-paper snippet off)
    - patches community-plugins.json (adds vimrc-support entry)

  One manual step after running:
    Open Obsidian → Settings → Community Plugins → Browse →
    install 'Vimrc Support'. Marketplace plugins can't be scripted.

  Obsidian must NOT be running when install.sh executes — it overwrites
  appearance.json / community-plugins.json on shutdown.

  Revert: remove the four symlinks (theme.css, manifest.json, vimrc,
  hotkeys.json), edit the JSONs by hand.

  ⚠  Editing hotkeys via Obsidian's UI rewrites hotkeys.json. Since the
  file is symlinked into the dotfiles repo, those edits land in the repo
  as a git diff — review & commit (or revert) as you would any change.
